CLIGEN Parameter File Creator

How to use this app:

  1. Select the location for new climate station in map
    (anywhere inside the black polygon)
  2. Enter scenario name
  3. Select time range
  4. Select model
  5. Click submit to download PAR file

Important project notes:

  • Dataset repositories:
    • SWPar4.5 for the CLIGEN Stochastic Weather Generator
    • SWPar8.5 for the CLIGEN Stochastic Weather Generator
  • NEX-DCP30 ~800m resolution (30 arc seconds) data was used for this project
